# Dependency map

Audit → architecture review → snapshot contract → feature matrix → grouped evaluation → versioned score fixture → backend → integrated dashboard → automated publication → recovery and CI → public handoff.

Backend reads can be designed against a synthetic run while ML work proceeds. The MVP gate requires a working database and backend. Manual imports use the same run schema as the later Prefect publisher. Public demo fixtures share the API shape. Warehouse access and AWS are independent of all nine mandatory phases.
