# Content Ranking MLOps

Local-first editorial decision support. An analyst chooses a client, inspects a prioritized queue, records a review and compares later observations. This repository currently contains the engineering specification. Runtime modules, datasets and deployment are future work.

Start with the [master PRD](docs/prd/MASTER_PRD.md), [environment audit](docs/phases/PHASE_00_REPOSITORY_AUDIT.md), [iteration roadmap](docs/roadmap/IMPLEMENTATION_ROADMAP.md) and [data rules](docs/governance/DATA_GOVERNANCE.md). Review the Phase 1 contract before implementing ingestion. Public demonstrations use generated records only.
